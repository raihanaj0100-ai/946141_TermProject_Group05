# Stock and Profit Management System

## Business Problem
ปัญหาการจัดการสต็อกสินค้าและคำนวณกำไร-ขาดทุนแบบเดิมที่ใช้กระดาษหรือการบันทึกด้วยมือ ทำให้เกิดความผิดพลาดได้ง่าย ตรวจสอบยาก และไม่สะดวกในการสรุปยอดขายรวม

## User
ผู้ดูแลร้านค้า / พนักงานขายหน้าร้านที่ต้องการระบบจัดการสินค้าและสรุปยอดขายสะสมอย่างรวดเร็ว

## Current Business Flow
การจดบันทึกรายการสินค้าและยอดขายลงสมุดบัญชีด้วยมือ เมื่อสิ้นวันต้องมานั่งคำนวณยอดเงินรวมและนับจำนวนบิลด้วยเครื่องคิดเลข ซึ่งเสียเวลาและเสี่ยงต่อการคำนวณผิดพลาด

## Proposed Program
โปรแกรม Java ที่ช่วยจัดการสต็อกสินค้า แสดงรายการสินค้า ตรวจสอบกำไรต่อชิ้น กำไรสุทธิ สต็อกคงเหลือ และสรุปยอดขายรวม ได้อย่างแม่นยำ

## Main Features
1. บันทึกและแสดงรายการสินค้าและสต็อกคงเหลือ 
2. สรุปกำไรต่อชิ้น กำไรสุทธิ 
3. สรุปยอดขายรวม

## Programming Concepts
- Selection (คำสั่งเงื่อนไข if-else / switch-case)
- Loop (การวนซ้ำเมนูการทำงาน do-while / for)
- Array (การเก็บข้อมูลสินค้าในหน่วยความจำชั่วคราว)
- Methods (การแบ่งฟังก์ชันการทำงานเป็นโมดูล)
- Text File (การอ่านและเขียนข้อมูลสะสมลงไฟล์ sales.txt)

## Data File
ชื่อไฟล์: sales.txt
โครงสร้าง: บันทึกข้อมูลตัวเลขยอดขายแบบ double precision เรียงต่อกันทีละบรรทัด

## How to Compile
javac StockandProfit.java

## How to Run
java StockandProfit
